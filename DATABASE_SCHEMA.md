# Database Schema

This document outlines the schema of the DuckDB database used in this application. The database is stored in the `fcst.duckdb` file.

## Schema: `da`

### Table: `da.forecast_versions`

Stores metadata about different versions of forecasts that are generated.

| Column Name          | Data Type | Description                                                                                      |
| -------------------- | --------- | ------------------------------------------------------------------------------------------------ |
| `version_id`         | `BIGINT`  | **Primary Key.** Unique identifier for the forecast version.                                     |
| `version_name`       | `VARCHAR` | A user-friendly name for the forecast version (e.g., "Q3 Forecast - Final").                     |
| `created_at`         | `TIMESTAMP` | Timestamp of when the forecast version was created.                                              |
| `location_hierarchy` | `VARCHAR` | The location hierarchy level used for this forecast (e.g., 'Region', 'Country').                 |
| `location_value`     | `VARCHAR` | The specific value for the location hierarchy (e.g., 'North America').                           |
| `product_hierarchy`  | `VARCHAR` | The product hierarchy level used for this forecast (e.g., 'Franchise', 'IBP Level 5').           |
| `product_value`      | `VARCHAR` | The specific value for the product hierarchy (e.g., 'Cardiology').                               |
| `user_name`          | `VARCHAR` | The name of the user who generated the forecast.                                                 |
| `forecast_horizon`   | `BIGINT`  | The number of periods (e.g., days, weeks) the forecast extends into the future.                  |
| `description`        | `VARCHAR` | A detailed description of the forecast version.                                                  |

### Table: `da.forecasts`

Stores the time-series forecast data generated by the models.

| Column Name      | Data Type | Description                                                                                             |
| ---------------- | --------- | ------------------------------------------------------------------------------------------------------- |
| `forecast_id`    | `BIGINT`  | **Primary Key.** Unique identifier for each forecast entry.                                             |
| `item_skey`      | `BIGINT`  | Foreign key referencing `da.product_hierarchy.demantra_item_skey`. The product being forecasted.        |
| `location_skey`  | `BIGINT`  | Foreign key referencing `da.location_hierarchy.location_skey`. The location for the forecast.           |
| `forecast_date`  | `DATE`    | The date for which the forecast value is predicted.                                                     |
| `model_type`     | `VARCHAR` | The name of the forecasting model used (e.g., 'Ensemble', 'NHITS').                                     |
| `forecast_value` | `DOUBLE`  | The predicted forecast value.                                                                           |
| `model_version`  | `VARCHAR` | The version of the model that was used to generate the forecast.                                        |
| `version_id`     | `BIGINT`  | Foreign key referencing `da.forecast_versions.version_id`. Links the forecast to a specific version.    |
| `override_value` | `DOUBLE`  | A value that can be used to manually override the `forecast_value`. If not `NULL`, this value is used. |

### Table: `da.sales_actuals`

Stores historical sales data.

| Column Name               | Data Type | Description                               |
| ------------------------- | --------- | ----------------------------------------- |
| `item_skey`               | `BIGINT`  | Foreign key for the product.              |
| `location_skey`           | `BIGINT`  | Foreign key for the location.             |
| `sales_date`              | `DATE`    | The date of the sales record.             |
| `act_orders_rev`          | `DOUBLE`  | Actual orders revenue.                    |
| `fcst_stat_prelim_rev`    | `DOUBLE`  | Preliminary statistical forecast revenue. |
| `fcst_stat_final_rev`     | `DOUBLE`  | Final statistical forecast revenue.       |
| `l2_stat_final_rev`       | `DOUBLE`  | Level 2 final statistical forecast revenue. |
| `fcst_df_final_rev`       | `DOUBLE`  | Final demand forecast revenue.            |
| `l2_df_final_rev`         | `DOUBLE`  | Level 2 final demand forecast revenue.    |
| `act_orders_rev_val`      | `DOUBLE`  | Actual orders revenue value.              |
| `l1_df_final_rev`         | `DOUBLE`  | Level 1 final demand forecast revenue.    |
| `l0_df_final_rev`         | `DOUBLE`  | Level 0 final demand forecast revenue.    |
| `fcst_df_final_rev_val`   | `DOUBLE`  | Final demand forecast revenue value.      |

### Table: `da.product_hierarchy`

A dimension table containing information about products.

| Column Name            | Data Type | Description                               |
| ---------------------- | --------- | ----------------------------------------- |
| `demantra_item_skey`   | `BIGINT`  | **Primary Key.** Unique key for the item. |
| `catalog_number`       | `VARCHAR` | The catalog number of the product.        |
| `business_sector`      | `VARCHAR` | Business sector for the product.          |
| `business_unit`        | `VARCHAR` | Business unit for the product.            |
| `franchise`            | `VARCHAR` | Franchise for the product.                |
| `product_line`         | `VARCHAR` | Product line.                             |
| `ibp_level_5`          | `VARCHAR` | IBP (Integrated Business Planning) Level 5. |
| `ibp_level_6`          | `VARCHAR` | IBP Level 6.                              |
| `ibp_level_7`          | `VARCHAR` | IBP Level 7.                              |
| `uom`                  | `VARCHAR` | Unit of Measure.                          |
| `pack_content`         | `VARCHAR` | Pack content description.                 |

### Table: `da.location_hierarchy`

A dimension table containing information about locations.

| Column Name             | Data Type | Description                               |
| ----------------------- | --------- | ----------------------------------------- |
| `location_skey`         | `BIGINT`  | **Primary Key.** Unique key for the location. |
| `country`               | `VARCHAR` | Country name.                             |
| `region`                | `VARCHAR` | Region name.                              |
| `area`                  | `VARCHAR` | Area name.                                |
| `selling_division`      | `VARCHAR` | The selling division.                     |
| `stryker_group_region`  | `VARCHAR` | Stryker group region.                     |
